Comprehensive AI Vision API for design template and image processing, generation and variation.

## Features (production)
- **Template Variation**: Optimize and generate variations of design templates
- **Background Removal**: Automatically remove backgrounds from images
- **Human Generation**: Generate photorealistic human images from text prompts with detailed control options
- **Stock Photo Generation**: Generate stock photo style images with enhanced prompts and detailed control options
- **Inpainting Removal**: Remove objects from images using AI inpainting
- **Image to Video**: Convert an uploaded image to a video
- **Job Status Tracking**: Monitor the progress and retrieve results for asynchronous AI vision tasks

## Base URLs (environments)
- **Development**: `https://api-mico-gen-ai.dev-craft.mico.one`
- **Staging**: `https://mico.gen.ai.stg-craft.mico.one`
- **Production**: `https://mico.gen.ai.craft.mico.one`

## Quickstart (cURL)
Generate a job (example: background removal), then poll for status.

```bash
curl --location 'https://mico.gen.ai.craft.mico.one/aivision/autoBackgroundRemoval' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --form 'file=@/path/to/image.png'
```

```bash
curl --location 'https://mico.gen.ai.craft.mico.one/aivision/jobs/{job_id}' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

## Authentication
All `/aivision/*` endpoints require Bearer authentication:

```bash
Authorization: Bearer YOUR_API_KEY
```

## Common workflow (sync vs async)
- **Async (returns `job_id`)**: most compute-heavy operations. Use **Get job status** to retrieve results.

## File upload limits
- Maximum file size: **35MB**
- Supported formats: **JPEG, PNG, WebP**
- Maximum files per request: **6**

## Prompt formats
Generation endpoints support:
- **String prompt** (simple)
- **JSON prompt object** (advanced control). The `text` field is optional and may be empty.

Example (simple):

```json
{
  "prompt": "A beautiful woman in a garden"
}
```

Example (advanced):

```json
{
  "prompt": {
    "text": "A beautiful woman in a garden",
    "category": "illustration",
    "style": "realistic photography",
    "background": "natural garden setting",
    "mood": "peaceful"
  }
}
```

## Services
Depending on the endpoint/config, requests may be processed by:
- **Gemini3.0** (primary)
- **OpenAI** (alternative)
- **Mico** (alternative)
