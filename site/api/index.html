    API Documentation

    This page contains the complete OpenAPI specification for the Mico Generative AI API.

    Generative AI API 1.0.0

    Comprehensive AI Vision API for image processing and generation using ComfyICU, Flux, and OpenAI platforms.

    Features

    • Background Removal: Automatically remove backgrounds from images
    • Object Extraction: Extract objects using bounding boxes or point selection
    • Human Generation: Generate photorealistic human images from text prompts with detailed control options
    • Stock Photo Generation: Generate stock photo style images with enhanced prompts and detailed control options
    • Image Outpainting: Extend images beyond their original boundaries
    • Image Inpainting: Fill in missing or damaged parts of images
    • Inpainting Removal: Remove objects from images using AI inpainting
    • Ad Variation: Generate ad variations with manual prompts or automatic analysis mode
    • Image Variations Recommendation: Get AI-powered recommendations for image variations

    Authentication

    All /aivision/* endpoints require authentication using one of the following methods:

    Bearer Token Authentication

    Use your API key with Bearer format: 

    Authorization: Bearer YOUR_API_KEY

    Note: /health and /documentation endpoints are publicly accessible and do not require authentication.

    File Upload Limits

    • Maximum file size: 35MB
    • Supported formats: JPEG, PNG, WebP
    • Maximum files per request: 10

    Services

    • Mico (ComfyICU): Primary AI service for most operations
    • Flux: Alternative service for inpainting and outpainting
    • OpenAI: Advanced service for inpainting and outpainting

    Rate Limits

    • Standard rate limiting applies
    • GPU accelerator options: low, medium, high

    Prompt Formats

    The API supports two prompt formats for generation endpoints:

    String Format (Simple)

    {
  "prompt": "A beautiful woman in a garden"
}

    JSON Format (Advanced)

    {
  "prompt": {
    "text": "A beautiful woman in a garden",
    "category": "illustration",
    "style": "realistic photography",
    "background": "natural garden setting",
    "mood": "peaceful"
  }
}

    JSON Format (Metadata Only)

    {
  "prompt": {
    "text": "",
    "category": "illustration",
    "style": "Japanese Manga pop style",
    "background": "urban cityscape",
    "mood": "peaceful"
  }
}

    The JSON format allows for detailed control over image generation by combining multiple properties into a single, well-formatted prompt. The text property is optional and can be empty, allowing for metadata-only prompts.

    POST /aivision/imageInpaintingRemoval

    Remove objects using inpainting

    Description

    Remove objects from an image using AI inpainting techniques. Supports Mico (ComfyICU), Flux, and OpenAI services. For Flux and OpenAI services, only the original image and prompt are required. For Mico service, both original image and mask are required.
